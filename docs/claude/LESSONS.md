## 2026-07-06 | CLAUDE.md 的行數與進度描述已腐化，照著做會改錯位置
- 根因：文件寫死了會變動的事實（檔案行數、「最新」進度），沒人負責更新。
- 規則：文件只寫穩定事實；會變的事實一律以 git log / 實際檔案為準。
- 歸宿：已併入 00-DIAGNOSIS.md #2 與新版 CLAUDE.md，此條留作範例。
